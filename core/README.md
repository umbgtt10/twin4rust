# twin4rust-core

The analysis behind [`cargo-twin4rust`](https://crates.io/crates/cargo-twin4rust):
which Rust source files have no mirrored test file beside them. This crate is
the package selection, the mirrored-path rule, its exemptions and the report;
the command, `cargo twin4rust`, is the `cargo-twin4rust` crate.

What it checks and why are in the
[main README](https://github.com/umbgtt10/twin4rust#readme) and
[`docs/RULES.md`](https://github.com/umbgtt10/twin4rust/blob/main/docs/RULES.md).
